# Zepto vs Blinkit: Quick-Commerce Performance Dashboard

## 📌 Project Overview
An interactive Excel dashboard designed to compare the operational efficiency and sales performance of India's leading quick-commerce giants, **Zepto** and **Blinkit**. The analysis is based on a dataset of **1,616 orders** tracking delivery metrics, customer satisfaction, and revenue trends across 5 major Indian cities.

## 🛠️ Tools & Techniques
- **Tool:** Microsoft Excel
- **Data Cleaning:** Standardized currency and date formats; handled missing values.
- **Advanced Features:** Pivot Tables, Slicers, Timeline, and dynamic KPI cards using `GETPIVOTDATA`.
- **Visualization:** Integrated bar charts, column charts, and clustered charts for side-by-side brand comparison.

## 📊 Dataset Description
The analysis utilizes the following data attributes:
- **Brand Performance:** Blinkit vs Zepto comparison.
- **Logistics:** Delivery Time (min) and City-wise distribution.
- **Financials:** Price, Quantity, and calculated Revenue.
- **Customer Behavior:** Payment Modes (UPI, COD, Card) and Ratings.

## 📈 Key Insights & Findings
Based on the pivot table analysis:

- **Speed King:** **Zepto** leads in delivery efficiency with an average of **13.69 mins**, significantly faster than Blinkit's **17.07 mins**.
- **Market Share:** **Blinkit** dominates in total revenue generation with **₹1.63 Cr**, while Zepto recorded **₹1.35 Cr** during the same period.
- **Top Category:** **Dairy** is the highest revenue-generating category for both brands, followed by Beverages.
- **Star City:** **Mumbai** leads the revenue charts among the analyzed cities.
- **Customer Satisfaction:** Both brands maintain a competitive rating, with Zepto slightly ahead at **3.00** vs Blinkit’s **2.95**.
